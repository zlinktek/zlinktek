The unified Windows client connects to supported ZLinkTek data recorders for device status, file listing, current and historical data download, configuration maintenance, time synchronization, and network diagnostics.

- **BlackBoxGuiClient:** graphical interface for commissioning, routine downloads, configuration, and field diagnostics
- **BlackBoxCmdClient:** command-line package for batch downloads, scripts, automated testing, and system integration
