## Product Positioning

IR100 is a general-purpose **industrial data recorder** for factory equipment, laboratory validation, and embedded-system testing. It combines common serial interfaces and Ethernet in one compact platform, providing a practical balance of interface coverage, reliability, and cost.

It is well suited to:

- Industrial equipment data recording and monitoring
- Data acquisition on small devices and unmanned platforms in moderate environments
- Development validation, prototypes, and low-volume production
- Long-duration communication logging in laboratories and test systems

## Key Features

- **Multiple interfaces:** Ethernet, RS422, RS485, RS232, and TTL
- **Wide-temperature operation:** designed for approximately -40°C to +85°C industrial environments
- **Cross-platform storage:** files can be accessed from Windows, Linux, and macOS
- **Network retrieval:** recorded data can be managed and downloaded through TFTP
- **Removable TF card:** convenient field replacement and offline transfer
- **Continuous operation:** industrial components and interference-resistant design support 24/7 recording

> IR100 does not provide electrical isolation. It is intended for sites with controlled grounding and relatively well-behaved electrical conditions. For reinforced isolation and protection, consider the [IR200 Series](/en/products/ir200/).

## Multi-Interface Transparent Recording

IR100 accepts common RS422, RS485, RS232, TTL, and Ethernet links without requiring separate conversion equipment. Multiple channels can be recorded on one device, which simplifies wiring and reduces the number of independent logging tools required at a test site.

The recorder focuses on preserving the original communication data, while protocol interpretation and application logic can remain in the host PC, SCADA platform, or analysis software. This separation keeps the recording path simple and makes the raw evidence available for later investigation.

## Reliability and Performance

- Storage and application processing are separated to reduce recording-path complexity
- Interface-side validation helps improve overall data integrity
- Industrial-grade components support long-duration unattended operation
- In a full-rate serial test, more than 10<sup>6</sup> bytes were continuously stored without packet loss in the tested configuration
- Typical bit-error performance is on the order of 10<sup>-6</sup> under representative operating conditions

## Data Retrieval and Analysis

- Retrieve files through Ethernet using the supplied TFTP tools
- Read stored data while recording continues, subject to the project configuration
- Remove the TF card for rapid offline transfer and analysis
- Integrate data into existing SCADA, host-computer, or custom analysis workflows

## Selection Guidance

| Requirement | Recommended Series |
| --- | --- |
| Standard industrial environment, broad interface coverage, cost-sensitive project | **IR100** |
| Complex grounding, long cables, stronger electrical protection, or unattended deployment | [**IR200**](/en/products/ir200/) |
| Severe shock, vibration, temperature extremes, or mission-critical recovery | [**JR100**](/en/products/jr100/) |

IR100 is normally the first choice when the environment is controlled and neither electrical isolation nor extreme-environment protection is required.
